Программа тестирования бэк-офисной антифрод системы Fraud-Analyze (BSS) 

1.1 Моделирование СБП документа:
    Шаг 1-ой итерации:
        СБП или нет: выбрать 1 ( это 1-я итерация )
        Нажать "Генерация документа" ( поле запроса будет заполнено )
        Нажать "Отправка документа" ( получим ответ на FA об обработке документа , в нём будет индикатор)
    Шаг 2-ой итерации:    
        СБП или нет: выбрать 2 ( это 2-я итерация )
        Нажать "Сохранить изменения" ( в запросе будет изменено только поле paymentSBP )
        Нажать "Отправка документа"
